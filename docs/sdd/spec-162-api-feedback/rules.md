# Reglas — SPEC-162

- Submit público no revela IDs internos ni existencia de sujetos concretos.
- Idempotencia, anti-bot y sanitización son obligatorios.
- Gestión interna usa concurrencia optimista y auditoría.
- Redacción aplica por default a contenido y PII.
- Retención gobierna purge/delete; no se falsifica borrado remoto.
