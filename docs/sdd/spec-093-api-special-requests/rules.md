# Rules — SPEC-093

- Crear una solicitud no implica `ACCEPTED`.
- Sólo actores autorizados pueden aceptar, rechazar o marcar `FULFILLED`.
- Texto libre es opcional, limitado, sanitizado y policy-driven.
- Requests especiales no sustituyen alergias, restricciones médicas ni códigos de seguridad.
- Logs y eventos omiten texto salvo canal/permiso explícitamente aprobado.
