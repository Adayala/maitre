# Contrato de entidad — SPEC-158 Rating

Rating representa una puntuación entera dentro de una escala versionada y una dimensión
definida, asociada a Feedback. Es inmutable salvo corrección auditada y no puede existir sin
consentimiento y contexto válidos. Tests cubren límites, escalas distintas, múltiples
dimensiones, duplicados, correcciones, feedback redactado, agregación y aislamiento entre
tenants.
