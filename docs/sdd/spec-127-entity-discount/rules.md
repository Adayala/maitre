# Rules — SPEC-127

- Discount policy y DiscountApplication son entidades distintas.
- Publicar congela versión; aplicaciones históricas no cambian de versión.
- Orden de aplicación: exclusiones, priority, porcentajes, fixed, caps.
- El descuento aplicado nunca vuelve negativa la base elegible.
- Correcciones usan aplicaciones compensatorias, no reescritura.
