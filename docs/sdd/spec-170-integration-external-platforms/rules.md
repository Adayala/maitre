# Reglas — SPEC-170

- Cada provider declara capacidades soportadas y no soportadas.
- Secrets viven fuera del dominio y raw payload no lo atraviesa.
- Sin spike `PASS` no se promete ni habilita el conector.
- Falla externa no bloquea feedback first-party.
- Debe existir exit strategy y evaluación de derechos/ToS.
