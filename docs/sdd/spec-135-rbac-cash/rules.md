# Rules — SPEC-135

- No existen wildcard ni roles locales implícitos por nombre.
- `finance` y `supervisor` son assignments/perfiles, no shortcuts de autoridad.
- Overrides, compensaciones riesgosas y approvals sensibles requieren segregación.
- Export y operaciones sobre threshold requieren step-up y audit.
- Sin LimitsPolicy aplicable se deniegan overrides/compensaciones riesgosas.
