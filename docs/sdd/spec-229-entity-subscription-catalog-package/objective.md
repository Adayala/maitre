# Objetivo — SPEC-229

## Propósito

Reducir la complejidad de la configuración inicial ofreciendo combinaciones recomendadas sin
volver al modelo rígido de planes que define capacidades en código.

## Criterios de aceptación

- [x] Existen opciones base, económica e intermedia.
- [x] La composición y cantidades son configurables y versionadas.
- [x] Aplicar un paquete no impide modificar después sus ítems individuales.
- [x] La UI explica qué incluye, beneficios y precio mensual estimado.
