# Contrato de reglas — SPEC-156 Fiscal Compliance

Validar antes y después de emisión ecuaciones, campos obligatorios, numeración, CAE, vigencias,
relaciones entre comprobantes y consistencia del Libro IVA mediante reglas versionadas. Cada
finding identifica norma/configuración, severidad y evidencia redactada; excepciones no pueden
fabricar autorización fiscal. Tests cubren datos incompletos, cambios normativos, certificados,
duplicados, notas, exportación, fallas externas y bloqueo seguro de producción.
