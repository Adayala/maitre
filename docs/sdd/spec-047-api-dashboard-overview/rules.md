# Rules — SPEC-047

- Permiso y alcance por sucursal filtran secciones.
- Cada metric code tiene definición/owner/fuente/version.
- Cada sección declara asOf/freshness/status/revision.
- Timeout/error no fabrica cero y permite respuesta parcial.
- Cache puede usarse si staleness es explícita; “real-time” no es garantía sin SLO.
- Overview operacional no reemplaza Analytics histórico.
