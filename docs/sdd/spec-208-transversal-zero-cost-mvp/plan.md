# Plan — SPEC-208

## Fase 1 — Inventario

1. Registrar proveedor, plan, términos, cuotas, owner y ambientes.
2. Clasificar límites hard, soft y comerciales.
3. Definir métricas y umbrales internos 50/75/90 %.
4. Identificar datos/recursos regenerables.

## Fase 2 — Guardrails

1. Configurar alertas disponibles y dashboards de uso.
2. Limitar emails, jobs, archivos, previews y concurrencia.
3. Automatizar limpieza de recursos temporales.
4. Definir degradación sin gasto automático.

## Fase 3 — Recuperación y salida

1. Implementar export/backup/restore según SPEC-220.
2. Probar build y ejecución fuera de Vercel.
3. Medir costo operacional humano.
4. Documentar triggers y alternativas de migración.

## Fase 4 — Pilot gate

1. Proyectar uso real con margen.
2. Revisar términos comerciales y privacidad.
3. Aprobar presupuesto o plataforma elegible.
4. Bloquear datos/operación real hasta completar la decisión.
