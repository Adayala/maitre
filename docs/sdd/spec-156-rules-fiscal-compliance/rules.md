# Reglas — SPEC-156

- Toda capacidad fiscal depende de source versions explícitas y aprobadas.
- Fuentes vencidas o no soportadas bloquean emisión segura.
- Findings deben registrar regla, fuente y evidencia redactada.
- Overrides operativos no fabrican autorización fiscal.
- Producción queda bloqueada sin homologación, revisión competente y runbook vigente.
