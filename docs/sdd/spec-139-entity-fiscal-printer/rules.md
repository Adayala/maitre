# Reglas — SPEC-139

- FiscalPrinter es adapter/capability opcional, no autoridad fiscal primaria.
- Secretos, SDK state y credenciales quedan fuera del agregado y del repositorio.
- Cambios de configuración se versionan y auditan.
- OFFLINE/RETIRED no bloquea WSFE/QR cuando la norma no exige hardware.
- Debe existir representación digital mínima cuando la normativa lo permita.
