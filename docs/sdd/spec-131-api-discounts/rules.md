# Rules — SPEC-131

- Sólo drafts son editables; versiones publicadas se versionan o desactivan.
- `evaluate` no reserva uso ni muta estado.
- `apply` revalida revision, vigencia, eligibility, stacking, caps y usage.
- Cliente no define importes, bases ni montos autoritativos.
- Overrides requieren permission separada, reason y threshold.
