# Contrato transversal — SPEC-212 Design System & Accessibility

Tokens, primitivas y patrones accesibles preceden features; WCAG 2.2 AA es el piso. Componentes
usan HTML semántico, teclado, foco visible, contraste, estados y textos externalizados; ninguna
biblioteca controla el dominio. Tests combinan axe, Testing Library y recorridos Playwright,
incluyendo zoom, reduced motion, lector de pantalla y operación táctil gastronómica.
