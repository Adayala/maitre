# Reglas — SPEC-143

- Plataforma administra el catálogo oficial; tenant no define alícuotas oficiales.
- No puede haber dos vigencias activas solapadas para la misma clave normativa.
- Versiones usadas por invoices emitidas son inmutables.
- Resolución fiscal exige source version aprobada y vigente.
- Cambios retroactivos crean nueva versión y revisión, no reescriben historia.
