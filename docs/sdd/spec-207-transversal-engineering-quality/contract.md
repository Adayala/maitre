# Contrato transversal — SPEC-207 Engineering Quality

Todo cambio parte de una spec aprobada y supera formato, lint, tipos, tests, cobertura de riesgo,
análisis estático, dependencias y seguridad sin bypass silencioso. Excepciones tienen owner,
motivo y vencimiento. La arquitectura aplica DRY sin abstracción prematura y SonarQube/SonarCloud
es reemplazable. Evidencia CI debe ser reproducible localmente y bloquear deuda nueva crítica.
