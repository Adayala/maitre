# Contrato transversal — SPEC-225 Spec & ADR Governance

Cada spec posee metadata, owner, reviewer, dependencias, criterios verificables y estado
gobernado; readiness no se infiere por cantidad de archivos. Decisiones arquitectónicas
durables usan ADR con consecuencias y supersession. Registro y validadores detectan IDs,
links, ciclos y drift. Sólo aprobación humana autorizada habilita implementación; excepciones
quedan fechadas y auditadas.
