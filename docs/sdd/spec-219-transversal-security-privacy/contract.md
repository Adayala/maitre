# Contrato transversal — SPEC-219 Security & Privacy

Threat modeling, least privilege, deny-by-default, validación server-side, cifrado, rate limits,
headers y gestión de dependencias aplican a todo incremento. Datos se clasifican, minimizan y
auditan; secretos y PII se redactan. Gates cubren SAST, secret scan, dependency review, OWASP,
tenant isolation y abuso. Riesgos críticos bloquean release y excepciones tienen vencimiento.
