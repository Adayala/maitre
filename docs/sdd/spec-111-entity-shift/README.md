# [SPEC-111] Shift

Shift representa una ventana operativa de trabajo dentro de una Branch para coordinar presencia, asignaciones y reporting básico sin reemplazar payroll o HR.

| Campo | Valor |
| --- | --- |
| **ID** | SPEC-111 |
| **Tipo** | Entity |
| **Dominio** | Workforce |
| **Estado** | IN_PROGRESS |
| **Readiness** | WALKING_SKELETON_I0 |
| **Review target** | READY_FOR_I0_REVIEW |
| **Prioridad** | P1 |
| **Owner / Reviewer** | UNASSIGNED / UNASSIGNED |
| **Blockers** | Acordar timezone, lifecycle y relación con assignments operativos |
| **Fase** | I0 |
