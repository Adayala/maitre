# Contrato de entidad — SPEC-188 Metric Definition

Define nombre, fórmula declarativa, dimensiones, unidad, ventana, timezone, fuente, owner y
versión. Publicar congela semántica y cambios incompatibles crean versión nueva; expresiones
son validadas y no ejecutan código arbitrario. Tests cubren ciclos, división por cero,
dimensiones prohibidas, vigencia, reproducibilidad y aislamiento.
