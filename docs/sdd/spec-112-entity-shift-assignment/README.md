# [SPEC-112] ShiftAssignment

ShiftAssignment vincula un actor operativo con un Shift y un scope de trabajo concreto, conservando trazabilidad y límites de autoridad sin redefinir RBAC global.

| Campo | Valor |
| --- | --- |
| **ID** | SPEC-112 |
| **Tipo** | Entity |
| **Dominio** | Workforce |
| **Estado** | IN_PROGRESS |
| **Readiness** | WALKING_SKELETON_I0 |
| **Review target** | READY_FOR_I0_REVIEW |
| **Prioridad** | P1 |
| **Owner / Reviewer** | UNASSIGNED / UNASSIGNED |
| **Blockers** | Acordar scopes operativos, conflictos simultáneos y vínculo con Shift |
| **Fase** | I0 |
