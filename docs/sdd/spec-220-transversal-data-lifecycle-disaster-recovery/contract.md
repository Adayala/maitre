# Contrato transversal — SPEC-220 Data Lifecycle & Disaster Recovery

Cada clase de dato define autoridad, retención, archivo, anonimización y borrado compatible con
obligaciones fiscales. Backups cifrados no cuentan hasta probar restore; RPO/RTO y runbooks se
validan periódicamente. Migraciones son forward-safe y exportaciones portables. Tests cubren
restore, corrupción, pérdida regional, tenant deletion, legal hold y evidencia de recuperación.
