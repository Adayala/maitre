# RULES — SPEC-208

1. No registrar tarjetas ni habilitar overage salvo aprobación explícita.
2. No fragmentar el sistema entre proveedores gratuitos sin una necesidad de spec.
3. Todo proveedor requiere exportación, backup o estrategia de reemplazo.
4. Los límites de cuota se modelan como configuración, no constantes dispersas.
5. Desarrollo, preview y demo no comparten secretos productivos.
6. Los datos de demo no incluyen información personal o fiscal real innecesaria.
7. Una capacidad no es production-ready solo porque funciona en un free tier.
8. Los términos de uso se revisan antes de cada piloto y release comercial.
9. El costo cero no justifica omitir seguridad, tests, backups ni observabilidad mínima.
10. Toda excepción de costo queda registrada con monto máximo, duración y responsable.
