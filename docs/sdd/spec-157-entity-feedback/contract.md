# Contrato de entidad — SPEC-157 Feedback

Feedback registra una opinión asociada opcionalmente a visita, orden o sucursal, con canal,
texto, purpose/base, timestamps y case lifecycle OPEN/TRIAGED/ACTION_REQUIRED/NO_ACTION/RESOLVED.
REDACTED describe contenido y no cierra el caso. La identidad se minimiza y separa; redactar
conserva evidencia y auditoría sin afirmar borrado remoto.
Tests cubren anonimato, duplicados, texto malicioso, retención, vinculación inválida,
moderación, PII y aislamiento entre tenants.
