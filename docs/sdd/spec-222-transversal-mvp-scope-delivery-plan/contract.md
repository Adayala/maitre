# Contrato transversal — SPEC-222 MVP Scope & Delivery Plan

El MVP se entrega por incrementos verticales priorizados con dependencia, owner, criterio de
entrada/salida y evidencia demo. Free tier, seguridad, accesibilidad y operación forman parte
del alcance, no tareas posteriores. Nada entra a implementación sin readiness aprobado; cambios
de alcance registran impacto, decisión y tradeoff. La ruta crítica evita construir features
bloqueadas por ADR o spike.
