# Rules — SPEC-133

- Se emite sólo al aprobar CashReconciliation.
- No sustituye submit/reject ni late adjustments.
- Payload mínimo excluye evidencia sensible y datos personales innecesarios.
- LateAdjustment posterior no modifica ni reemite este hecho.
- Reintentos no producen un segundo hecho lógico equivalente.
