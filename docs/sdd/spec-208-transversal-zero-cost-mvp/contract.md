# Contrato transversal — SPEC-208 Zero-Cost MVP

Desarrollo y demo operan dentro de free tiers con registro versionado de cuotas, alertas y
degradación antes del límite. Ningún proveedor entra al dominio: puertos, PostgreSQL estándar,
exports y runbooks preservan salida. Activar tráfico comercial, pago o superar límites requiere
decisión explícita. Tests verifican budgets, apagado seguro y recuperación desde exportación.
