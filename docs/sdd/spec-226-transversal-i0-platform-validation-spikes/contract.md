# Contrato transversal — SPEC-226 I0 Platform Validation Spikes

Spikes I0 responden hipótesis acotadas de Vercel, Supabase, toolchain, UI y operación con pasos,
fixtures, límites medidos, costo y evidencia reproducible. No producen arquitectura productiva
oculta ni convierten candidatos en decisiones. Cada resultado es PASS/FAIL/INCONCLUSIVE y
actualiza ADR, riesgos y exit strategy. Secrets usan entornos de prueba y todo recurso creado
incluye limpieza documentada.
