# Reglas — SPEC-157

- Contenido, sujetos e identidad opcional se modelan por separado.
- `REDACTED` no equivale a cierre del caso.
- Transiciones operativas requieren expected revision y auditoría.
- Redacción preserva provenance y no afirma borrado externo.
- Identidad opcional sólo se expone bajo permisos y propósito válidos.
